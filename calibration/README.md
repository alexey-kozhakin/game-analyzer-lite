# Калибровка формулы "рейтинг партии"

Формула в приложении ([src/main.js](../src/main.js)):

```
estimatedElo = clamp(A - B * ln(1 + acpl / C), 400, 2900)
```

где `acpl` — средняя потеря в centipawns за партию для одной стороны.
Сейчас `A=2882, B=320, C=10` — подобраны на глаз. Этот каталог считает
A, B, C по факту: Chess.com отдаёт реальный рейтинг игрока на момент
каждой партии (`game.white.rating` / `game.black.rating`), поэтому можно
подобрать формулу так, чтобы `estimatedElo` был как можно ближе к этому
реальному рейтингу на большом наборе партий.

## Установка

```bash
cd calibration
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
brew install stockfish   # если ещё не стоит; версия 18 — та же, что в браузере
```

## 1. Скачать партии

```bash
python fetch_games.py --username alexey-kozhakin
```

Можно указать несколько игроков (`--username` несколько раз) — это даёт
больше точек и более широкий диапазон рейтингов для калибровки, а не
только твой личный узкий диапазон:

```bash
python fetch_games.py --username alexey-kozhakin --username some-friend
```

Партии (только `rapid`, отфильтровано по умолчанию) сохраняются в
`data/raw/<username>.json`. Повторный запуск ничего не перекачивает,
пока не передать `--force`.

## 2. Посчитать ACPL по каждой партии

```bash
python analyze_games.py
```

Прогоняет Stockfish (depth 12, как в приложении) по каждому полуходу
каждой скачанной партии — так же, как это делает `src/main.js`
(предыдущий анализ переиспользуется как "before" для следующего хода).
Результат — `data/dataset.csv` со строками `(acpl, rating)` по каждой
стороне каждой партии. Скрипт можно прерывать и перезапускать — уже
посчитанные партии (по `url`) не пересчитываются.

Это самый долгий шаг. Для быстрой проверки на подмножестве:

```bash
python analyze_games.py --limit 20
```

## 3. Подобрать A, B, C

```bash
python calibrate.py
```

Сначала быстрый grid-search по C (при фиксированном C формула линейна
по A и B — решается напрямую через МНК), затем дообучение всех трёх
параметров через PyTorch (Adam) от найденной точки. Скрипт печатает
MSE/MAE на трейне и на отложенной выборке (`--test-split`, по
умолчанию 20%), сохраняет результат в `data/calibration_result.json` и
выводит готовую JS-строку для вставки в `src/main.js`.

```bash
python calibrate.py --method grid   # без PyTorch, если torch не хочется ставить
```

## Ограничения

- ACPL за одну партию — шумная величина, поэтому чем больше партий,
  тем стабильнее калибровка.
- Если калибровать только на одном аккаунте, кривая точна вблизи его
  рейтинга, но может плохо экстраполироваться на сильно другие уровни
  игры — стоит добавить несколько разных игроков через `--username`.
